# 🌐 Animated Portfolio Website

A sleek and responsive portfolio website built using **React.js** and **Tailwind CSS**.

## 🚀 Live Demo

🔗 [View Portfolio Live](https://amishb.com.np)

## 🛠️ Tech Stack

- ⚛️ React.js
- 🎨 Tailwind CSS
- 💾 Vercel(for deployment)

## 🧑‍💻 How to Use

### 1. Clone the Repo

```bash
git clone
cd your-repo-name
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Run the App

```bash
npm start
```

### 4. Build for Production

```bash
npm run build
```
